# Игра для Кати: Telegram Mini App

Статический сайт (HTML/CSS/JS), без сервера и базы данных. Открывается внутри Telegram через бота.

## Структура

```
index.html          каркас экранов
css/style.css       стили (mobile-first)
js/config.js        ВСЕ настройки: имена, дата открытия
js/universes.js     5 миров-пародий + финал (пока заглушки)
js/app.js           ядро: Telegram SDK, диалоги, хаб, прогресс
assets/             photos / video / audio / avatars
```

## Как это работает

- Игра ждёт даты `UNLOCK_AT` из `js/config.js`, до неё показывает обратный отсчёт.
- Прогресс сохраняется на устройстве и в облаке Telegram (CloudStorage).
- Для тестов добавь `?dev=1` к адресу, и ворота с таймером пропускаются.

## Быстрая проверка у себя на компьютере

```bash
cd kate-game
python3 -m http.server 8000
```

Открой `http://localhost:8000/?dev=1` и включи в браузере режим телефона (F12, значок устройства).

## Размещение (бесплатно, ~5 минут)

Нужен адрес **https**: Telegram не открывает http.

**Вариант A: Cloudflare Pages / Netlify (проще всего)**
1. Зарегистрируйся на netlify.com или pages.cloudflare.com.
2. Перетащи папку `kate-game` в окно загрузки (Netlify: Sites → Add new site → Deploy manually).
3. Получишь адрес вида `https://something.netlify.app`.
4. В настройках сайта смени имя на неочевидное, чтобы ссылку нельзя было угадать.

**Вариант B: GitHub Pages**
1. Создай репозиторий, загрузи файлы.
2. Settings → Pages → Deploy from branch → main.
3. Адрес: `https://<логин>.github.io/<репозиторий>/`.

## Подключение к Telegram

1. В Telegram открой **@BotFather**, команда `/newbot`, задай имя и username бота.
2. Команда `/newapp`, выбери бота, задай название и описание.
   В поле **Web App URL** вставь https-адрес из предыдущего шага.
   Если спросит фото 640×360, загрузи любую картинку.
3. BotFather выдаст ссылку вида `https://t.me/<бот>/<короткое_имя>`. Это и есть ссылка на игру.
4. Дополнительно: `/setmenubutton`, чтобы у бота появилась кнопка «Играть» внутри чата.

## Как отправить Кате

- Лучше отправить ссылку **с нового аккаунта-«посланника»** или через самого бота, чтобы сообщение выглядело загадочно.
- Не присылай ссылку заранее: ворота с таймером откроются сами, но сюрприз лучше сохранить.

## Важно

- Все, у кого есть адрес сайта, смогут открыть файлы, включая фото из `assets/`. Не клади туда ничего слишком личного, а адрес делай неугадываемым.
- Перед загрузкой фото сжимай (до ~300 КБ), видео делай короткими (до нескольких МБ, формат MP4 H.264).
- После каждого обновления файлов загружай папку заново; Telegram иногда кэширует старую версию (помогает закрыть и открыть игру).

## Мир Heroes of Magic (3-й мир)
Сюжет: Ван болеет, Кася идёт за 5 артефактами (кольцо, леопардовый плащ, сигареты, бандана, скейт) через 4 локации.
Файлы: `js/heroes_core.js` (боевая логика, работает и в Node), `heroes_data.js` (статы, баланс, энкаунтеры),
`heroes_story.js` (локации и сцены), `heroes_ui.js` / `heroes_battle.js` / `heroes_map.js` (движок),
`hmini_arm.js`, `hmini_cups.js`, `hmini_mk.js` (мини-игры: армрестлинг, стаканы, «Компы»), `css/heroes.css`,
ассеты в `assets/heroes/` (видео H.264, аудио `barinov.mp3`).
Тест: `?dev=1&reset=1` (сброс прогресса), `?hfast=1` ускоряет бой. Прогресс: `localStorage` `kate_heroes_v1`.
